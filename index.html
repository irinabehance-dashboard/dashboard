Синхронизация между устройствами

Отметки сохраняются в твой репозиторий на GitHub. Ключ нужно ввести один раз на каждом устройстве — он хранится только в этом браузере.

  1. Открой github.com → новый токен.
  2. Название любое, срок — 1 год. Repository access → Only select → dashboard.
  3. Permissions → Repository → Contents: Read and write. Нажми Generate и скопируй ключ.
